# UCP Ecosystem public data repository

Owner: Jake / UCPList product owner

Application: <https://ucplist.ai>

Repository: `Full-Vibe/ucp-ecosystem`

## Purpose

This public repository is the community-editable data surface for the UCPList ecosystem directory. It exists so developers, agents, and contributors can inspect, cite, validate, and propose corrections to structured UCP ecosystem data.

## Scope

This repository contains public listing data, its schema and validator, contribution guidance, and public documentation. It does not contain the UCPList application source, private services, secrets, credentials, customer data, or internal operational tooling.

## Source relationship

The private UCPList application is the product surface. Changes to factual claims in this repository follow [CONTRIBUTING.md](CONTRIBUTING.md): every new or substantively updated record needs a source URL, verification date, and evidence status. Historical evidence backfill is tracked in [TODO.md](TODO.md).

## Maintenance

The UCPList product owner reviews external contributions and is responsible for evidence quality, public-repository hygiene, and synchronization with user-facing directory claims.
